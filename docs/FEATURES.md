# 功能手册

个人向运营台：热点 → 文案 → 视频 → 人工确认发布，叠加客户跟进、知识库与股票研究。  
全站右下角提供 **智仔 · 数据问答**（不进侧栏），基于知识库 / 文案等系统数据检索作答。

## 模块一览

| 模块 | 路径 | 能做什么 |
|------|------|----------|
| 总览 | `/` | **数据大屏**（KPI、图表、本周发布复盘）；积压待办走顶栏待办铃 |
| 内容情报 | `/hot-topics` | **双板块**：①股票情报（早间财经新闻→生成股市简报→AI 分析总结（分开））②热点选题（全网热榜 + 官方数据台按互动排序爆款文案）；不做视频号登录爬虫 |
| 文案中心 | `/scripts` | AI/手动文案、日更计划与出片（沿用上次成功视频参数）；文案会进入智仔向量索引 |
| 视频中心 | `/videos` | 配音 → 字幕 → 合成；失败可重试；素材分场景/BGM/封面；成功参数记忆 |
| 发布中心 | `/publish` | **准备发布**（复制文案+打开官方页）→ 你在平台点发表 → 确认已发；自动填充为高级高风险选项 |
| 客户管理 | `/customers` | 客户档案、跟进、提醒中心 |
| 线索池 | `/leads` | 公众号预约等留资；可转为客户 |
| 知识库 | `/knowledge` | 笔记、AI 对比；可上传 PDF/录音抽文本；**智仔主要检索源** |
| AI Agents | `/agents` | Agent 提示词与运行记录 |
| AI 助手 | `/workflows` | 客户/运营/发布助手任务 |
| 市场概览 | `/stocks` | 全市场、筛选、策略 |
| 自选股 | `/stocks/watchlist` | 自选/持仓现价、目标价预警、复盘 |
| 系统设置 | `/settings` | 统一入口（页内切换模块）：AI、采集、**官方数据台**、发布、配音视频、内容参数等 |
| 智仔 · 数据问答 | 全站浮动 | 见下方专节；不占侧栏菜单 |

## 顶栏

- **待办**：待出片文案 / 待生成视频 / 待发布 / 待跟进客户（空分类不展示）；点击可深链到对应页并带筛选
- **提醒**：客户日程提醒（生日、保单、跟进等）+ 股价预警（跌破成本 / 触及目标价）

## 智仔 · 数据问答（桌宠）

- **入口**：任意已登录后台页右下角浮动桌宠「智仔」，点击打开对话；**不进**侧栏「AI 智能」
- **能力**：向量检索（知识库 / 文案；股票意图时含简报）+ Agent 编排 + 引用卡片；可切换「智能 / 偏知识库 / 偏文案 / 偏股票」
- **专用工具**：
  1. **金融实时**（股票/资金合一个）：北向资金、沪深港通分板块、行业资金净流入/流出等，按需拉行情，**不进知识库**
  2. **保险常识**：内置常青要点（等待期、重疾与医疗差异等）+ 定向检索知识库/文案
  3. **自选股**：持仓、跌破成本、预警
- **意图路由**：口播/文案创作走知识库+文案；北向/行业资金走金融工具；保险常识走保险工具；避免用时事新闻污染知识库
- **依赖**：系统设置中已启用可用大模型；库内无相关段落时会如实说明资料不足（非故障）
- **充实知识库**（检索才有料）：
  1. 知识库页「新建」：标题带关键词，正文按主题拆条（建议 300～2000 字），填分类与标签
  2. 「上传 PDF/录音」导入条款、培训材料等
  3. 条目「AI 处理」生成摘要/标签，便于命中
  4. 优质口播也可放进文案中心（文案同样被索引）
- **索引**：首次提问或源表新增后会自动重建 `rag_chunk`；也可 `POST /api/pet-chat/reindex` 强制重建；`GET /api/pet-chat/status` 查看索引状态
- **对话 API**：`POST /api/pet-chat`（body：`message`、`mode`、`session_id` 可选）
- **说明**：股票相关回答不构成投资建议；引用分数过低会被过滤

原型示意：`docs/prototypes/pet-data-chat.html`

## 内容流水线

1. **股票情报**：早间抓取财经新闻推送到本页 →「生成股市简报」与「AI 分析总结」分开展示（设置可开早间自动获取）
2. **热点选题**：采集公开热榜（微博/百度等）和/或官方数据台 API → 按互动分排序选题
3. 生成或日更文案 → 「出片」创建视频任务
4. 视频：Edge TTS 配音 → 字幕 → MoviePy/FFmpeg 合成
5. 发布：复制文案 + 打开官方创作者页 → 你手动上传点发表 → 「确认已发」回写链接

## 官方数据台

- 入口：`/settings/commercial`
- 配置：Base URL、API Key、榜单路径、鉴权方式、JSON 列表路径与标题/热度字段映射
- 使用：内容情报 → 热点选题 →「拉官方数据台」；设置页可「试拉」验连通
- **合规**：只调用你已开通的官方/企业接口或合规网关，不用 Cookie 爬网页

## 股市简报（内容情报 · 股票）

- 入口：`/hot-topics` →「股票情报」
- 数据：东财全球资讯、财联社电报、财经向热搜过滤
- 能力：今日简报、AI 分析、一键推送（需配置消息推送渠道）
- 自动：`/settings/content` 中 `自动生成股市简报` / `简报自动推送微信` / 执行整点

## 风控说明（重要）

- **不要**用无头浏览器 / Cookie 自动登录去扒抖音、小红书作品或自动点发布，个人号极易封禁。
- 平台口播采集默认关闭；发布默认安全模式（`publish.mode=manual`）。
- Playwright 自动填充仅作高级实验，需二次确认，不推荐日常使用。

## 日更说明

「今日计划并出片」默认：**采全网热点 → 写文案（约 2 流量 + 1 干货）→ 创建视频任务**。  
不包含：各平台口播专项采集、自动点平台发表。发布需到发布中心人工确认。

## 视频依赖

- 配音：`edge-tts`（默认可免 Key）
- 合成：`moviepy`（推荐）；系统 FFmpeg 用于测时长与 FFmpeg 引擎
- **不需要**安装剪映

## 配置就绪

设置页检查项包括：AI Key、内容选题（热榜即可）、发布平台启用、FFmpeg（可选）、Playwright（可选）。平台 Cookie 不再作为日常发布的必要条件。
