# 功能手册

个人向运营台：热点 → 文案 → 视频 → 半自动发布，叠加客户跟进、知识库与股票研究。

## 模块一览

| 模块 | 路径 | 能做什么 |
|------|------|----------|
| 总览 | `/` | **数据大屏**（指标/动态）+ **今日工作台**（待办/配置就绪）；顶栏待办/提醒 |
| 内容情报 | `/hot-topics` | 全网热点 / 平台口播采集、评分、生成文案 |
| 文案中心 | `/scripts` | AI/手动文案、日更计划与出片、出片进视频任务 |
| 视频中心 | `/videos` | 配音 → 字幕 → 合成/导出；失败可重试；素材与场景 |
| 发布中心 | `/publish` | 半自动打开创作者后台填表；确认已发并回写链接 |
| 客户管理 | `/customers` | 客户档案、跟进、提醒中心 |
| 知识库 | `/knowledge` | 笔记整理与 AI 对比 |
| AI Agents | `/agents` | Agent 提示词与运行记录 |
| AI 助手 | `/workflows` | 客户/运营/发布助手任务 |
| 股票研究 | `/stocks` | 自选股现价、筛选、策略、复盘 |
| 系统设置 | `/settings/*` | AI、采集、发布、配音视频、内容参数 |

## 顶栏

- **待办**：待出片文案 / 待生成视频 / 待发布 / 待跟进客户（空分类不展示）；点击可深链到对应页并带筛选
- **提醒**：客户日程提醒（生日、保单、跟进等）

## 内容流水线

1. 采集热点（需平台 Cookie 时按设置）
2. 生成或日更文案 → 「出片」创建视频任务
3. 视频：Edge TTS 配音 → 字幕 → MoviePy/FFmpeg 合成
4. 发布：Playwright 打开后台填充 → 你在平台点发表 → 「确认已发」回写链接与时间

## 日更说明

「今日计划并出片」默认：**采全网热点 → 写文案（约 2 流量 + 1 干货）→ 创建视频任务**。  
不包含：各平台口播专项采集、自动点平台发表。发布需到发布中心人工确认。

## 视频依赖

- 配音：`edge-tts`（默认可免 Key）
- 合成：`moviepy`（推荐）；系统 FFmpeg 用于测时长与 FFmpeg 引擎
- **不需要**安装剪映

## 配置就绪

总览「配置就绪」与设置页检查项包括：AI Key、采集 Cookie、发布 Cookie、Playwright、FFmpeg（可选）。未就绪会提示去对应设置。
