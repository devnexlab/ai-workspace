# 社媒工作台改进技术方案（个人号 · 合规版）

> 范围：在**不升级企业号/蓝V**、**不自动私信/代发**的前提下，增强现有内容工作台。
> 现状依据：`backend/modules/publish/workbench.py`、`publisher.py`、`routes/publish/publish.py`。
> 约束：视频号/抖音/小红书均为个人号；无官方开放客服 API 时，**不做**粉丝抓取、点赞抓取、私信致谢、批量代发。

---

## 1. 合规结论（已裁剪）

| 能力 | 状态 | 说明 |
|---|---|---|
| 作品数据看板 + 手动/低频同步 | **落地** | 只读自己创作者后台，已有能力 |
| 视频号官方「关注后自动回复」引导与状态标记 | **落地** | 官方能力，本系统只记「已开启」勾选 |
| 半自动/全自动私信致谢、抓粉丝/点赞者 | **不做** | 灰区，账号与合规风险高 |
| 互动自动灌入 CRM | **不做** | 依赖上述灰区能力 |

发布护栏不变：默认 `manual`；`autofill` 须用户显式开启。

---

## 2. 设计原则（红线）

- **只读自己的登录态作品数据**，不买号、不注入他人 Cookie、不养号、不代发私信。
- **欢迎粉丝等互动**：引导使用各平台**官方**能力（如视频号助手「关注后自动回复」），不在本系统模拟发送。
- **同步拟人化、默认可关**：自动同步默认关闭；开启后每天最多 1 次、夜间整点窗口、平台间节流。

---

## 3. 改进项一：视频号官方关注后自动回复（零代码 + 状态位）

视频号满足条件（如已实名）时可在官方后台开通：

1. 打开「视频号助手」→「私信管理」
2. 开启「关注后自动回复」，填写欢迎语
3. 可选：关键词自动回复承接咨询

工作台侧：

- 设置项 `workbench.official_auto_reply_shipinhao`（用户勾选「已在官方开启」）
- `build_workbench()` 的 `platforms` / `prefs` 带出该标记，供看板展示
- **不抓取、不发送任何私信**

---

## 4. 改进项二：作品数据同步常态化（低风控）

复用 `batch_sync_workbench()`（创作者后台导入作品 + 刷新播放/赞/评/转/藏）。

- 模块：`modules/publish/scheduler_sync.py`，挂入 `content_ops/scheduler.py`
- 配置（`system_setting` / category=`workbench`）：
  - `sync_auto_enabled`：默认 `false`
  - `sync_run_hour`：默认 `3`（建议 2–5 点）
  - `sync_last_run` / `sync_last_run_date`：防同日重复
- 策略：每天 1 次；整点后约 50 分钟窗口；多平台顺序同步，平台间短暂 sleep；失败记日志不重试轰炸
- 设置页「定时任务」可开关；工作台页也可开关
- 接口：`GET/PUT /api/publish/workbench/prefs`

---

## 5. 明确不做（合规剔除）

- `thanks_task` / 粉丝列表抓取 / 点赞者抓取
- Playwright 打开私信框代发「谢谢关注/点赞」
- 批量一键致谢、无人值守发送
- 社媒互动自动 upsert 进 CRM

若未来有企业号官方 API，再单独立项，不走个人号爬虫发送。

---

## 6. 风险清单（落地范围）

| 动作 | 风险 | 控制 |
|---|---|---|
| 同步自己作品数据 | 低 | 自用登录态、默认关、每天 1 次 |
| 官方关注后回复（平台侧） | 无（官方） | 本系统仅状态勾选 |
| 代发私信 / 抓互动对象 | — | **已剔除** |
